دستیار آزمایشی مبحث ۱۹ (ویرایش پنجم)

این دستیار آزمایشی مبحث ۱۹ است. برای تصمیم‌های مهم مهندسی، پاسخ را با منبع استنادشده تطبیق دهید.
آزمایش بسته: پرسش‌ها و بازخوردهای شما برای ارزیابی و بهبود این دستیار ذخیره می‌شود؛ لطفاً اطلاعات شخصی یا محرمانه وارد نکنید. تصمیم‌های مهم مهندسی را با منبع استنادشده مبحث ۱۹ تطبیق دهید.
